# 바이브 레벨 테스트 · 구글 앱스크립트 배포판

디자인과 기능은 원본과 같습니다. 응답 저장 위치만 Firebase에서 **구글 시트**로 바꿨습니다.

| 파일 | 넣을 곳 |
|---|---|
| `Code.gs` | 앱스크립트 편집기의 `Code.gs` |
| `index.html` | 앱스크립트 편집기에 새로 만드는 HTML 파일 `index` |

## 배포 순서 (10분)

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. 이름 예: `바이브 레벨 테스트 응답`
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs`를 붙여 넣습니다.
4. 왼쪽 **파일 옆 `+` → HTML**을 누르고 이름을 `index`로 정합니다(`.html`은 자동으로 붙음). 내용을 지우고 `index.html`을 통째로 붙여 넣습니다.
5. 💾 저장한 뒤 위쪽 함수 목록에서 `setup`을 고르고 **실행**합니다.
   - 권한 승인 창이 뜹니다. **고급 → (안전하지 않음)으로 이동 → 허용**을 누르세요. 내 시트에만 접근하는 권한입니다.
   - 시트에 `응답` 탭과 `요약 그래프` 탭이 생기면 성공입니다.
6. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형: **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
7. **배포**를 누르면 나오는 웹 앱 URL(`…/exec`)이 참여자 주소입니다.

## 주소

- 참여자: `웹앱URL` (회차를 나누려면 `웹앱URL?r=1기`)
- 교사 화면: `웹앱URL?teacher` (회차가 있으면 `웹앱URL?teacher&r=1기`)

교사 화면 위쪽에도 두 주소가 표시됩니다. 참여자 첫 화면 아래의 **교사 화면으로 가기** 링크로도 들어갈 수 있습니다(비밀번호 없음).

## 구글 시트 그래프 (`요약 그래프` 탭)

`setup`을 실행하면 `요약 그래프` 탭이 자동으로 생깁니다. 응답이 쌓이면 표와 차트가 저절로 바뀌고, 따로 새로 고칠 필요는 없습니다.

- **B1 칸**에서 회차를 고르면 그 회차만 집계합니다. `전체`를 고르면 모든 회차를 합쳐서 보여 줍니다.
- 차트 4개: 레벨 분포, 영역별 평균, 1번 문항(바이브코딩 설명) 응답, 문항별 평균
- 탭을 지웠거나 망가졌으면 시트 메뉴 **바이브 테스트 → 요약 그래프 만들기 / 다시 만들기**를 누르세요. 메뉴는 시트를 새로 열면 나타납니다.
- `요약 그래프` 탭은 다시 만들 때 통째로 지워지니, 직접 메모할 내용은 다른 탭에 적어 두세요.

## 알아 두기

- **코드를 고친 뒤**에는 **배포 → 배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 주소는 바뀌지 않습니다.
- 교사 화면은 **4초마다** 새 응답을 확인합니다. 간격은 `index.html`의 `POLL_MS`에서 바꿀 수 있습니다.
- 학교·교육청 구글 계정은 '모든 사용자' 공개가 막혀 있을 수 있습니다. 그럴 때는 개인 Gmail 계정으로 만드세요.
- 응답은 시트의 `응답` 탭에 한 줄씩 쌓입니다. Q1~Q12 칸은 보기 번호가 아니라 **점수(0~2)** 입니다.
- 점수: 문항당 0~2점, 영역당 6점, 총 24점. 레벨 구간은 0–5 / 6–10 / 11–15 / 16–20 / 21–24점입니다.
- 문항이나 보기를 바꾸면 `index.html`의 `Q`와 `Code.gs`의 `Q_LABELS`, `Q1_OPTS`도 같이 맞춰 주세요.
- 총점과 레벨은 서버에서 다시 계산하므로 조작된 점수는 저장되지 않습니다.
- 응답을 비우려면 시트에서 2행부터 지우면 됩니다(1행 제목줄은 남겨 두세요).
- 교사 화면 주소에는 비밀번호가 없습니다. 주소를 아는 사람은 이름과 점수를 볼 수 있으니 실명 대신 별명을 권장합니다.
- `index.html`을 브라우저에서 바로 열면 지금처럼 **데모 모드**로 동작합니다(배포 전 미리 보기용).
